Champaran Satyagreh from akshat
चंपारण सत्याग्रह (1917):

1917 मे ं महात्मा गांधी ने बिहार के चंपारण जिले में किसानो ं पर हो रहे अंग्रेजों के अत्याचारों के खिलाफ सत्याग्रह शुरू किया। किसानों को जबरदस्ती नील की खेती करनी पड़ती थी। गांधीजी ने अहिंसात्मक आंदोलन चलाकर किसानों को न्याय दिलाया। यह भारत मे ं गांधीजी का पहला सफल सत्याग्रह था।
